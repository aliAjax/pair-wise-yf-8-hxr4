# 胶片分镜条核对台

一个纯前端本地应用，用来整理纸质放映胶片片段、拖拽调整放映顺序、统计总时长、筛选颜色偏移，
并把放映机导出的实际记录贴进来逐条对账、自动生成装盘方案与试映前破损提醒。

直接打开 `index.html` 即可使用，也可以在本目录启动静态服务访问。

## 功能

- **实际记录对账**：把放映机导出的记录整段贴进文本框，每行一条。编号会先归一化
  （全角转半角、忽略大小写、空格和 `- _ / ／` 等分隔符，`A-001`、`a001`、`A 001`、`Ａ－００１`
  都认成同一条），再与计划逐条匹配：
  - 计划有、实际没放：红色标出；
  - 实际有、计划没有：先挂"待确认"，可一键补入计划；
  - 时长对不上的已匹配项会标出，可用实际时长覆盖计划（覆盖后自动重算装盘）。
- **装盘方案**：每本盘容量固定（`REEL_CAPACITY`，当前 60 秒，在 `app.js` 顶部调整）。
  按放映顺序贪心装盘，装不下自动往后一本顺延；接片破损（破损情况含"接片"）的片段
  不允许落在盘尾——装不下时把接片段顺延到下一本开头；顺序约束下确实无法避开盘尾的，
  会在装盘卡片和"试映前核对"里红色告警。
- **作废重算**：片段时长一改（卡片上直接改），或顺序、增删变化，装盘方案、盘号和
  试映提醒立即全部重算，不存在旧盘号残留。
- **旧数据升级**：localStorage 里没有盘号（`reel`）和实际记录（`actualText`）字段的旧数据，
  加载时自动补默认值并重算盘号；原有的备注（`note`）和缩略图（`thumb`）原样保留。
